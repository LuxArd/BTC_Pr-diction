# Data sources

## Source categories used in the original study

| Category | Original access approach | Notes |
| --- | --- | --- |
| Bitcoin on-chain indicators | JSON files obtained from Blockchain.com chart data | The original JSON files are not bundled in this portfolio repository. |
| Bitcoin and market prices | Yahoo Finance, accessed through yfinance | The original notebook requests data up to January 2024. |
| External market variables | Selected equity, foreign-exchange, commodity, and energy-related symbols | Availability and meanings must be verified before a reproducible rerun. |

## Reproducibility boundary

Downloaded market data is not committed to this repository. A refreshed analysis must record the source endpoint, retrieval date, symbol or indicator name, transformation steps, and permitted versioned snapshot information.

Data providers can revise historical series, change terms, or remove endpoints. A rerun may therefore differ from the source notebook; such differences should be reported rather than hidden.
