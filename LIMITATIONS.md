# Limitations and responsible use

## Methodological limitations identified in the source study

- Some aggregate and seasonal transformations were created before the temporal split, which can expose a model to future information.
- Model tuning used generic cross-validation rather than a validation strategy designed for time series.
- Several reported metrics were calculated after a logarithmic transformation, so they are not directly interpretable as Bitcoin price errors.
- The original evaluation period ends in January 2024 and does not establish present-day performance.
- Historical financial relationships can change abruptly; past fit does not establish future forecasting ability.

## Portfolio interpretation

The value of this project is its learning journey: data acquisition, feature exploration, model comparison, and the ability to identify how a course prototype should be strengthened.

The project should not be interpreted as evidence of a profitable trading strategy or a deployable financial product.
